2. _What a .hpp file is_ An hpp file is a text file, which can also be .h or .hh. It severs as a header. Each cpp file is called a translational unit. Headers exist to share declarations between different translational units without duplicating definitions. Usually, a header includes class definitions, function declarations, type aliases, enums, constants, and template implementations. .cpp files contain function bodies, and file local helpers. 
3. keywords:
	1. _const_: read only. Once a const variable is set, it cannot be changed. When const is put at the end of a method, it means that the method is read only, and does not change any of the object's variables. 
	2. _explicit vs implicit_: sometimes, cpp compiler implicitly changes the var type by assumption. Explicit makes it output a compiler error, avoiding future debugs. 
	3. _\#_pragma once_: This tells the compiler to skip the file after processing once. 
	4. namespaces: cpp uses namespaces to organize as opposed to python's file paths. A namespace is a virtual container under a specific name. 
	5. _struct_: a struct is a way to group data, very similar to a class, except in struct, everything is public by default, whereas in class, everything is private by default
	6. _void_: means the function returns nothing
	7. _fstream_: package in cpp that lets you read from and write to files. 
	8. _IValue_ a container that holds any libtorch value
	9. _std:cerr_ stream for printing error messages to the console

Latency Logger. 

It logs latencies for preprocessing, inference, decoding, language model at p50, p95, p99. So far, only the forward pass is implemented. Others will be left for implementation later on. We leave them as stub functions. 

The components are stored in a __named-scope timer__, as to avoid having to rename hardcoded start/stop variables often. We want to store as `std::unordered_map<std::string, std::vector<double>>`. For preprocessing, decoding, etc, we have stub scopes. We define 
<center> total = wall clock from first byte in to last byte out <center>
because there may be overhead between them. Computationally, it is timer.start("total")/timer.stop("total").

_notes_
1. _name-scoped timer:_ Known as RAII-based timer (resource acquisition is initialization), where the timer starts when resource is allocated for the variable, and stops when object goes out of scope. 
2. _std::unordered_map:_ uses a hashtable, stores elements in key-value pairs, unlike _std::map_ which stores them in a balanced binary tree. 
3. _auto:_ auto is a keyword for automatic type deduction. Based on the value initialized, the compiler determines the type
4. _static_cast:_ converts one data type into another at compile time. 
5. _i++ vs ++i:_ both increment i by 1. However
	1. i++ first delivers the value, then increments
	2. ++i first increments, then delivers the value
