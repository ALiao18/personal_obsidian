Some wisdom for future research
1. partition the code well. I think a good approach is: each notebook should be self contained, meaning to run it, only one command is required. Moreover, calculations and figures should be in separate files, which brings us to the second point
2. record everything, and label it by date. When pulling the info, that can be an easy edit where you just change the date and then one can generate all the necessary figures in one click
3. version control. I need to have better version control for data, for code, for everything. learn to fucking use git
